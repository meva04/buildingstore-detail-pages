스케치업의 완성형 올인원 솔루션

V-Ray for Windows

스케치업에서 곧바로 완성하는 최고 수준의 실사형 렌더링

사실적인 조명, 정밀한 재질, 카메라 시뮬레이션을 통해
고객의 마음을 움직이는 시각적 결과물을 만듭니다.

실시간 렌더링 (V-Ray Vision)

모델을 수정하면 조명과 재질 효과가 화면에 바로 반영되어, 작업 중에도 결과를 확인합니다.

조명 시뮬레이션 (라이트젠)

몇 번의 클릭으로 실내외 자연광과 인공조명 분위기를 연출하고 비교합니다.

고품질 재료 라이브러리

수 천개의 PBR 텍스쳐 및 오브젝트를 프로젝트에 바로 적용해 사실적인 모델링을 생성해 보세요.

통합 관리 센터 (V-Ray Asset Editor)

재질, 조명, 렌더링 설정까지 한곳에서 제어해 작업 흐름을 이어갑니다.

Revit to SketchUp 완벽 호환 솔루션

Revit Importer

호환 오차 없이 바로 불러오는 Revit to SketchUp

*.rvt 파일 그대로 오차 없이 불러와, 스케치업 환경에서 빠르고 정밀하게 3D 작업을 이어갑니다.

속성부터 스케일 그대로

레빗의 재질, 카테고리, 요소 ID 등 속성 데이터는 물론 단위 설정과 스케일까지 오차 없이 정확하게 가져옵니다.

태그 & 구성요소 자동 변환

레빗의 모델 구조를 보존하여 패밀리 유형과 레이어를 스케치업 태그(Tag)와 구성요소(Component)로 자동 매핑합니다.

용량 최적화로 가볍게

불필요한 폴리곤을 자동으로 줄여 모델 용량을 최적화하고, 스케치업에서 가볍고 쾌적하게 작업합니다.

원하는 3D 뷰 가져오기

레빗 파일 전체를 무겁게 불러올 필요 없이, 필요한 3D 뷰에 정의된 요소(패밀리·컴포넌트)만 선택해 빠르게 불러옵니다.

스캔 데이터 기반 정밀 역설계 모델링

Trimble ScanEssentials

스캔 데이터 기반 3D 모델링부터
오차 검증까지 한 번에

주요 포인트 클라우드 포맷(E57·LAS·PLY)을 지원해, 스케치업 안에서 오차 없이 3D 모델링하는 전용 솔루션입니다.

다양한 스캔 포맷 호환

E57, LAS, LAZ, PLY 등 다양한 스캔 데이터를 클릭 한 번으로 불러옵니다.

자유로운 정렬 & 시각화

스캔 데이터를 원하는 위치에 정렬하고, 밀도·높이·색상 기준으로 필터링해 확인할 수 있습니다.

클리핑 박스로 작업 최적화

불필요한 영역은 잘라내고 원하는 특정 위치만 가볍게 모델링합니다.

실제와 오차 정밀 검증

실제 현장 스캔 데이터와 3D 모델을 비교하여 오차를 정밀하게 확인합니다.

3D-to-Field 굴착 및 토공 솔루션

Trimble Site Contractor

스케치업 3D 모델, 측량 장비·굴착기와 연동

굴착 지오메트리를 손쉽게 모델링하고,
현장 컨트롤러 및 장비 제어 파일(.dxf, .ttm)로 내보냅니다.

지형 모델 내보내기

스케치업 지형을 Siteworks 태블릿이 읽을 수 있는 파일로 변환합니다.

굴착 장비 연동

굴착 장비 모니터로 설계 도면과 정밀 굴착 높이를 실시간 제공합니다.

컨트롤 포인트 좌표 맞춤

오프셋 입력과 마커 지정으로 스케치업 원점과 실제 현장 좌표를 매칭합니다.

현장 측량 지형 가져오기

현장에서 측량한 데이터를 가져와 지형에 맞춰 설계를 즉시 검토·수정합니다.

현장 좌표-3D 도면 정밀 연결 도구

Trimble Field Points

현장 측점 데이터(RTS)와 스케치업 포인트를
오차 없이 상호 호환

큰 측량 좌표를 스케치업 모델 원점 근처로 옮기고,
모델의 레이아웃 포인트를 현장 배치 파일로 내보냅니다.

원점 오프셋 설정

현장 좌표를 모델 원점 근처로 옮겨 작업하고, 원래 좌표로 되돌린 후 내보냅니다.

설계 포인트 생성 및 변환

클릭, 좌표 직접 입력, 줄자 안내점 변환으로 설계 포인트를 만들어 모델에 배치합니다.

TFLX / CSV 내보내기

작성한 포인트를 Field Link용 .tflx 파일 및 범용 CSV로 내보내 현장 배치에 활용합니다.

레이어별 색상 표시

포인트를 스케치업 태그별 색상으로 구분해 표시하고, 모델에서 종류별로 확인합니다.

이 제품에는 SketchUp Pro가 포함되어 있습니다.

공통 안내사항
  1. 라이선스 발급 순서결제 완료 후 트림블 본사의 승인을 거쳐 라이선스가 발급됩니다. 승인이 완료되면 결제 시 입력하신 이메일로 안내 메일이 발송됩니다. 메일 수신 후 빌딩포인트코리아에서 발송한 활성화 가이드에 따라, 라이선스 활성화 및 계정 할당을 진행해 주세요.
  2. 라이선스 유지보수모든 스케치업 라이선스는 발급일로부터 1년 간의 기술지원 서비스 비용이 포함되어 있습니다. 빌딩포인트코리아 기술지원팀 support@buildingpoint.co.kr
주문 및 라이선스 정책
  1. 환불 조건라이선스 발급일 기준 7일 이내 라이선스를 활성화하지 않은 경우 환불이 가능합니다.
  2. 반품 / 환불 예외 사항소프트웨어 상의 문제를 제외한 기타 다른 이유로 인한 반품/환불 불가
  3. 결제 관련카드결제 취소의 경우 카드사 또는 PG사 사정에 따라 취소 완료까지 최대 15일까지 소요될 수 있습니다. 가상계좌 입금 후 취소의 경우 당사와 PG사 환불 규정에 의해 15일 이내 환불됩니다. 취소 시 발생하는 모든 수수료(카드취소, 입금 후 취소)는 고객 부답입니다.
라이선스 발급 안내

본 상품은 라이선스가 발급되는 상품으로, 라이선스 발급에 영업일 기준 평균 1~2일 소요됩니다.
